Trial by Trace

Benchmarking AI agent harnesses for reliability and failure attribution.

A correct outcome is only part of the evidence. TraceTrial-Bench scores task completion and harness reliability separately, and traces every verdict back to what happened during execution.

01The approach

The harness manages context, tools, execution, and state. It is part of the agent system, and it deserves an evaluation of its own.

Layer 01 · Agent

Did the task succeed?

Were the required artifacts, actions, and task constraints satisfied? Executable or state-based criteria check the actual delivery.

Layer 02 · Harness

Was the harness reliable?

Were context, tool results, and execution states preserved and delivered faithfully? Separate criteria check the mechanisms, even when the task succeeds.

  1. 1Trace collection
  2. 2Multi-source evidence & Trace IR
  3. 3Layered evaluation
  4. 4Evidence-based attribution review

Measurement validity is checked separately. Candidate links and co-occurring failures are not, by themselves, validated causal effects.

03What we measure

95 tasks target specific mechanisms while preserving native harness behavior. Coverage varies by dimension; Verification currently contains one task scenario.

C

Context

Retention, truncation, compaction, and recovery.

E

Execution

Processes, exit status, timeouts, and interaction.

G

Governance

Permissions, safety policies, and isolation boundaries.

L

Lifecycle

Sessions, delegation, and state continuity.

O

Observability

Failure signals, diagnostics, and visible evidence.

T

Tools

Tool discovery, interfaces, and call routing.

V

Verification

Faithful delivery of verification actions and results.
