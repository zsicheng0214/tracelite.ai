01 / THE APPROACH

Measure the outcome.
Examine the process.

The harness manages context, tools, execution, and state. It is part of the agent system—and a subject of evaluation in its own right.

LAYER 01

Agent performance

Were the required artifacts, actions, and task constraints satisfied? Executable or state-based criteria evaluate the actual delivery.

Evaluates task outcomes↗
LAYER 02

Harness reliability

Were context, tool results, and execution states preserved and delivered faithfully? Separate criteria examine the mechanisms, even when the task succeeds.

Evaluates execution mechanisms↗
EVIDENCE CHAIN

Trace collection → Multi-source evidence & Trace IR → Layered evaluation → Evidence-based attribution review

Measurement validity is checked separately. Candidate links and co-occurring failures are not, by themselves, validated causal effects.

Reading the traces: Agent / Harness fractions are passed criteria / total criteria for each individual run, not success rates over repeated trials. Excerpts and field summaries follow the report appendix; recorded tool text is preserved in English.
