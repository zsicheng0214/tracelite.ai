Read the scores, not just the rank

Task success and harness reliability answer different questions.

01

Overall score

The equal-weight mean of Agent Score and Harness Macro, computed from unrounded run fractions. It summarizes both layers without replacing either one.

02

Task pass & Agent score

Task pass requires every Agent criterion to pass. Agent Score averages the passed fraction per run, retaining partial credit when the task is not fully completed.

03

Harness macro & Clean

Harness Macro averages each run’s fraction of passed Harness criteria. Clean is stricter: every criterion in both the Agent and Harness layers must pass.

Evaluation scope

Every model–harness pair covers the same 95 tasks. Harness aggregates pool nine models, or 855 selected runs per harness. The archive retains one selected execution per cell, including recovery replacements; these are descriptive results, not estimates of repeated-run stability.

Cost estimates use recorded token usage and frozen model-specific prices. They exclude Judge calls, discarded runs, storage, and tool charges. Token totals and cost are reported values; rounded input and output counts may not sum exactly to rounded totals.
