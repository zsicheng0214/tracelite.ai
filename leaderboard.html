Nine models, four agent harnesses, the same 95 tasks. Every number is taken from Table 7 of the Trial by Trace report.

# Harness Layered score Task pass % Agent score Harness macro % Both clean % Tokens / run (k) Cost / run ($)

Layered score is the 50/50 mean of the Agent layer (did the task get done) and the Harness layer (did the harness meet its obligations). Task pass requires every Agent criterion; Both clean requires every criterion in both layers. Each cell is one scored run per task under high reasoning.

These are descriptive results on the selected executions, not significance claims. Cost is the estimated Agent cost at frozen gateway prices, judge cost excluded.
